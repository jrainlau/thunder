# 零界回声：天穹余烬

原创 2D 纵版科幻飞行射击 H5。包含 10 架可三级进化的战机、6 类战斗武器、10 个专属大招、20 个常规关卡、2 个隐藏关卡和 22 个独立 BOSS。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 移动：`WASD`、方向键、鼠标/触屏拖动
- 武器：自动射击；拾取武器模块后按 `E` 或点击“装配”
- 大招：同步能量满后按 `X` 或点击右下角大招按钮
- 暂停：`Esc` 或右上角暂停按钮

## 系统

- 武器模块：脉冲机枪、棱镜激光、浮游炮群、炽流霰炮、蜂群导弹、轨道蓄能炮，均可强化至 W3。
- 战机成长：每架战机从 Lv.1 升至 Lv.3，升级改变六维能力、被动、形态和大招表现。
- 剧情：四幕主线与两章隐藏剧情，黑匣子和 BOSS 核心逐步揭示欧米伽真相。
- 存档：进度保存在本机 `localStorage`，包含安全校验和备份回退。

## 验证

```bash
npm run lint
npm test
npm run build
```
